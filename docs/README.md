## وصف المشروع
هذا المشروع عبارة عن نظام إدارة مكتبة رقمية مبسط تم تطويره باستخدام مفاهيم البرمجة الكائنية (OOP). يهدف النظام إلى إدارة الكتب والمستعيرين وعمليات الإعارة والاسترجاع بطريقة منظمة وفعالة.

## متطلبات التشغيل
- لغة البرمجة: أدخل اللغة المستخدمة java ,iml
- أدوات التطوير: [أدخل الأدوات المستخدمة، مثلاً Visual Studio Code أو IntelliJ IDEA]
- إدارة الإصدارات: Git
- مستودع المشروع: GitHub
## هيكلة المشروع
- src/: يحتوي على الكود المصدري للمشروع.
  - Book.java: صنف Book لإدارة معلومات الكتب.
  - Borrower.java: صنف User لإدارة معلومات المستعيرين.
  - BorrowingProcess.java: صنف BorrowingProcess لإدارة عمليات الإعارة.
  - PhysicalBook.java:الصنف الفرعي للكتب الورقية
  - EBook.java:الصنف الفرعي للكتب الالكترونية
  - Main.java: الملف الرئيسي لتشغيل النظام.
- docs/: يحتوي على ملفات التوثيق.
  - README.md: ملف الشرح الحالي.
- LibrarySystem.iml:الواجهة الرسمية لنظام.

   ### كيفية تشغيل المشروع 

1. تحميل المشروع:
   - اضغط على زر "Code" في مستودع GitHub الخاص بالمشروع.
   - اختر "Download ZIP" وحفظ الملف على جهازك.
   - فك ضغط الملف بعد التحميل.

2. فتح المشروع:
. فتح المجلد الرئيسي للمشروع (المجلد الذي يحتوي على ملفات src و docs).

3. تشغيل البرنامج:
   - افتح ملف Main.py (أو الملف الرئيسي الموجود في مجلد src).
   - اضغط على زر التشغيل في برنامجك (مثل VS Code) أو انقر نقرًا مزدوجًا على الملف.

## ميزات النظام
- إضافة كتب جديدة (ورقية أو إلكترونية).
- إضافة مستعيرين جدد.
- إدارة عمليات إعارة الكتب.
- استرجاع الكتب من المستعيرين.
- البحث عن الكتب أو المستعيرين.
- عرض الكتب المعارة من قبل مستعير معين.

## تصميم الكود وتنفيذ المشروع
- تم تطبيق مفاهيم البرمجة الكائنية مثل:
  - التغليف (Encapsulation): لحماية بيانات الكائنات.
  - الوراثة (Inheritance): لإنشاء أصناف متخصصة (مثل كتاب ورقي وكتاب إلكتروني).
  - تعدد الأشكال (Polymorphism): للتعامل مع الكائنات المختلفة بطريقة موحدة.
  - الواجهات (Interfaces): لتحديد السلوكيات المشتركة بين الأصناف.
- تم استخدام Git و GitHub لإدارة الإصدارات وتتبع التغييرات.
